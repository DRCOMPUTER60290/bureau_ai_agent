Connecteurs MCP

Ajoute un serveur HTTP/SSE de confiance ou un connecteur local prédéfini. Cocher un connecteur autorise tous ses outils pour les tâches suivantes; certains outils peuvent modifier des données.

Chargement des connecteurs…

Gmail Connector local — Ajoute le serveur MCP jwlutz/gmail_connector déjà installé, avec la commande cmd /c gmail-connector. Le programme doit être accessible dans le PATH Windows et avoir terminé sa configuration Gmail.

Gmail Connector est ajouté en mode brouillons + classement par défaut. Google demande les scopes Gmail modification + envoi; Bureau 3D bloque l'envoi, la suppression de brouillons, la corbeille et la suppression de libellés. Pour réautoriser un compte en écriture, ouvre PowerShell et exécute $env:GMAIL_MCP_MODE = "full", puis gmail-connector auth <alias>; accepte les nouveaux droits Google. Sans cette variable dans le terminal d'authentification, le compte reste en lecture seule. Le bouton lecture seule permet de retirer ces autorisations.

Connecter Gmail — La connexion nécessite le serveur Gmail MCP de Google (en aperçu développeur) et un client OAuth Google. Attention : Google refuse les adresses personnelles @gmail.com pour l'inscription au programme Preview; une adresse Google Workspace sur domaine d'entreprise est obligatoire. Si tu n'as qu'une adresse Gmail personnelle, ce connecteur officiel ne pourra pas fonctionner pour le moment. Le formulaire remplace l'ancienne entrée Gmail et demande les scopes Gmail lecture + composition. Le scope composition permet aussi l'envoi via l'API Gmail, mais le serveur MCP Google n'expose actuellement pas d'outil d'envoi. Claude Code ouvrira ensuite le consentement Google dans une fenêtre locale.

  1. Inscris une adresse Google Workspace et le numéro de projet Cloud au programme Developer Preview Google Workspace.
  2. Dans Google Cloud Console, active Gmail API et Gmail MCP API, puis crée un client OAuth Web. Ajoute l'URI de redirection http://localhost:8765/callback et choisis « Use this client for an AI-powered agent ». Guide Google complet.
  3. Mets Claude Code à jour en version 2.1.231 ou ultérieure pour le rappel OAuth local.
